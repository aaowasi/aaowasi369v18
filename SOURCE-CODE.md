# Source code

The source ZIP contains every runtime file, build script, policy, schema, test, workflow and document needed for this edition. `site/` is the public source and `dist/` is regenerated by `npm run build`. The Python engine and historical baseline records remain outside the public build.

Start with `README.md`, then `docs/EXECUTION-GUIDE.md` and `docs/ARCHITECTURE.md`. Review the actual verification results in `docs/VALIDATION.md`.
