## Retention decisions

- Keep all original baseline JSON and the separate historical-evidence archive. Existing source records preserve the basis for review.
- Keep human-readable policies and signed evidence when useful. A document format alone is not grounds for deletion.
- Public build contains only `site/`. Private contracts, raw logs and original evidence archives do not enter `dist/`.
- No fabricated savings, customer quotes, platform endorsements, or certification badges were added.
- Existing `work/<domain>/` URLs remain valid. The main page provides consolidated browsing and source-aware interactive tools.
- Vanta, Drata, ServiceNow, OneTrust and paid BI embeds were not added as unverified proficiency claims.

## Residual scoring decision

The original register includes scores such as 7, which cannot be a product of integer likelihood and impact values from 1–5. Reconstructing coordinates would invent evidence. The matrix therefore shows inherent coordinates from source data, preserves original residual scores in the register, and permits session-only residual exploration. Scenario positions never overwrite historical scores or persisted evidence.
